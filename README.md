# Connect-Med Hub

Crie um site simples chamado 'Connect-Med' para conectar médicos a redes de telemedicina. As redes podem solicitar médicos informando dias e tempo de plantão, e os médicos podem aceitar ou recusar. O site deve ter cadastro, login e um painel básico para envio e resposta das solicitações, com design claro, moderno e fácil de usar
